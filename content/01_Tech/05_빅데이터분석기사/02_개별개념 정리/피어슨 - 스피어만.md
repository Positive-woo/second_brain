### 피어슨 상관계수

두 변수의 직선 관계
선형 관계의 '강도'를 측정하는 상관계수

- 1 : 완전한 양의 선형 관계
- 0 : 선형 관계 없음
- -1 : 완전한 음의 선형 관계

-1 <= r <= 1

- 연속형 변수 사용함
- 선형 관계만 확인함
- 이상치 (outlier)에 민감함

### 스피어만 상관계수

두 변수의 순위(rank) 사이의 관계를 측정하는 상관계수
순서가 얼마나 같이 변하는지 측정함

- 1 : 완전한 양의 단조 관계 (순위가 완전 동일함)
- 0 : 단조 관계 없음
- -1 : 완전한 음의 단조 관계 (순위가 완전히 반대)

- 비모수 방법
- 순위 (rank) 사용
- 단조 관계 측정
- 이상치 영향이 상대적으로 작음
