# TCP와 UDP

TCP와 UDP는 모두 IP 네트워크에서 데이터를 전달할 때 쓰는 전송 계층 프로토콜이다.

## TCP

**TCP**는 연결을 만들고, 순서와 전달 여부를 확인한다.

- 신뢰성 있는 전달이 중요할 때 많이 쓴다.
- 웹 접속, 파일 전송 등에 널리 쓰인다.
- 데이터를 보내기 전에 연결 과정을 거친다.

## UDP

**UDP**는 연결 확인과 재전송 절차가 단순하다.

- 지연을 줄이는 데 유리하다.
- 음성, 영상, 게임, DNS 질의 등에 쓰인다.
- 전달을 보장하지 않으므로 필요한 보완은 응용 프로그램이 맡을 수 있다.

## 구분 기준

- 정확성과 순서가 중요하면 TCP가 어울린다.
- 빠른 전달과 낮은 지연이 중요하면 UDP가 어울린다.
- 같은 포트 번호라도 TCP 8080과 UDP 8080은 전송 프로토콜이 다르므로 함께 존재할 수 있다.

## 퀴즈 기록

TCP/UDP 구분 퀴즈는 **B가 정답**이었다. 문제의 선택지 문구는 현재 기록에 남아 있지 않다.
