# DHCP, DNS, NAT, PAT

## DHCP

**DHCP**는 네트워크에 접속한 기기에 필요한 설정을 자동으로 나눠준다.

- IP 주소
- 기본 게이트웨이
- DNS 서버
- 기타 네트워크 설정

## DNS

**DNS**는 `example.com` 같은 이름을 IP 주소로 찾아준다.

주소록에서 사람 이름으로 전화번호를 찾는 것과 비슷하다.

## NAT

**NAT**는 네트워크 경계에서 IP 주소를 다른 주소로 바꾸는 기술이다.

가정용 공유기는 내부 사설 IP와 외부 공인 IP 사이를 변환하는 데 NAT를 흔히 사용한다.

## PAT

**PAT**는 여러 내부 통신을 하나의 공인 IP로 내보내면서 포트 번호도 함께 바꾸어 각각의 통신을 구분하는 방식이다.

가정용 NAT라고 부르는 기능은 실제로 PAT를 포함하는 경우가 많다.

## 예시

내부 `192.168.0.10:51000`에서 인터넷 서버 `8.8.8.8:443`에 연결할 때 공유기는 출발지를 `공인IP:61000`으로 바꿀 수 있다.

응답이 오면 공유기는 기록을 보고 원래 내부 기기인 `192.168.0.10:51000`으로 다시 전달한다.

## 개념 구분

- DNS는 이름을 IP 주소로 찾는다.
- NAT/PAT는 통신이 네트워크 경계를 지날 때 주소와 포트를 변환한다.
- DNS가 포트포워딩을 대신하는 것은 아니다.
