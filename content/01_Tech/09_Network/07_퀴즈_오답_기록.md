# 퀴즈와 오답 기록

## 퀴즈 기록

| 퀴즈 | 점수 | 기록된 오답 |
|---|---:|---|
| 네트워크 기초 10문항 | 7/10 | 4번 사설 IP, 5번 NAT, 10번 NAT 응용 |
| 복습 6문항 | 4/6 | 2번 사설 IP 범위, 5번 NAT와 DNS 구분 |
| 포트 10문항 | 6/10 | 2번 HTTPS 포트, 4번 TCP/UDP에서 같은 번호 사용, 5번 출발지·목적지 포트, 6번 포트포워딩 |

## 점수 정정

이전에 네트워크 10문항 점수가 6/10으로 적힌 답변이 있었지만, 학습 기록에 따른 정확한 점수는 **7/10**이다.

## 다시 볼 포인트

- 사설 IP 범위
- NAT와 DNS의 역할 차이
- TCP와 UDP에서 같은 포트 번호를 사용할 수 있는 이유
- 클라이언트의 임시 출발지 포트와 서버의 서비스 포트 구분
- 포트포워딩의 방향과 대상

## 미응답 질문

아래 질문은 학습 중 남겨 둔 질문이다.

> 서버가 `내 PC:55000 -> 서버:443` 요청을 받았다. 응답 패킷의 목적지 포트는 무엇일까?

정답은 `55000`이다. 서버 응답은 보통 `서버:443 -> 내 PC:55000` 흐름으로 돌아온다.
