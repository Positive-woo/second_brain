# 포트와 포트포워딩

## 포트

**포트 번호**는 한 기기 안에서 어느 프로그램 또는 통신 대상으로 데이터를 전달할지 구분하는 번호다.

- TCP와 UDP 각각 `0~65535` 범위를 가진다.
- 포트는 IP 주소와 함께 봐야 한다.
- 같은 번호라도 TCP와 UDP는 구분된다.

## 서버 포트와 클라이언트 포트

서버는 서비스가 사용하는 목적지 포트를 열어 둔다.

- HTTP는 보통 TCP 80을 사용한다.
- HTTPS는 보통 TCP 443을 사용한다.
- SSH는 보통 TCP 22를 사용한다.
- HTTP/3는 UDP 443도 사용한다.

클라이언트는 보통 운영체제가 고른 임시 출발지 포트를 사용한다.

예시: `내PC:55000 -> 서버:443`에서 `55000`은 내 PC의 임시 출발지 포트이고, `443`은 서버의 HTTPS 서비스 포트다.

## 응답 패킷의 포트

서버가 `내PC:55000 -> 서버:443` 요청을 받았다면, 서버 응답은 대체로 다음처럼 돌아온다.

```text
서버:443 -> 내PC:55000
```

따라서 응답 패킷의 목적지 포트는 `55000`이다.

## 포트포워딩

**포트포워딩**은 외부에서 공유기의 특정 포트로 들어온 연결을 내부 기기의 주소와 포트로 전달하는 설정이다.

예시: 외부 사용자가 `공유기공인IP:9000`에 접속하면 공유기가 `192.168.0.10:8080`으로 전달하도록 설정할 수 있다.
