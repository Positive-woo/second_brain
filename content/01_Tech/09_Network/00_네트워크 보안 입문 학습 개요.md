# 네트워크 보안 입문 학습 개요

> 학습 기준일: 2026년 10월 12일
> 대상: 네트워크를 처음 배우는 입문자

## 학습 목표

- 네트워크 기초 용어를 일상적인 예시로 설명할 수 있다.
- IP, 포트, DNS, NAT처럼 자주 나오는 개념을 서로 구분할 수 있다.
- 보안 관점에서 DDoS, 방화벽, IDS, IPS의 기본 역할을 이해한다.
- macOS에서 관찰용 명령을 사용해 현재 네트워크 상태를 확인한다.

## 현재까지 배운 큰 흐름

1. BPS, PPS와 DDoS
2. TCP와 UDP
3. 라우터, 게이트웨이, 스위치
4. 공인 IP와 사설 IP
5. DHCP, DNS, NAT, PAT
6. 포트와 포트포워딩

## 학습 원칙

- 개념은 먼저 쉬운 비유로 잡고, 이후 실제 패킷 흐름으로 연결한다.
- 명령어는 관찰 용도로만 사용한다.
- 익숙하지 않은 외부 시스템을 스캔하거나 허가되지 않은 네트워크에서 시험하지 않는다.
- 오답은 틀린 기록이 아니라 다음에 다시 볼 체크포인트로 남긴다.
