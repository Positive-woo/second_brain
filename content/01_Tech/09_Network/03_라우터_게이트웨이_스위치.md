# 라우터, 게이트웨이, 스위치

## 스위치

**스위치**는 같은 LAN 안에서 기기들을 연결한다.

- 보통 목적지의 MAC 주소를 참고해 프레임을 전달한다.
- 같은 집이나 사무실 네트워크 안에서 기기끼리 통신할 때 관여한다.

예시: 같은 집 네트워크의 노트북과 프린터가 통신할 때는 LAN 안에서 전달이 이뤄진다.

## 라우터

**라우터**는 서로 다른 IP 네트워크 사이에서 패킷이 갈 다음 경로를 선택한다.

- 내부 네트워크와 외부 인터넷 사이의 길목 역할을 한다.
- 집 공유기는 라우터 기능, 스위치 기능, 무선 AP 기능을 함께 제공하는 경우가 많다.

## 기본 게이트웨이

**기본 게이트웨이**는 내 컴퓨터가 다른 네트워크로 나갈 때 우선 패킷을 보내는 라우터의 주소다.

예시: 인터넷 사이트에 접속할 때 내 컴퓨터는 보통 기본 게이트웨이인 공유기로 패킷을 보낸다.

## 퀴즈 기록

같은 LAN에서 목적지 기기를 연결하는 장치를 고르는 문제는 **B가 정답**이었다.
