# AWS 시험 학습 목차

AWS 관련 자격시험을 준비하며 개념·서비스 선택 기준·오답 이유를 축적하는 학습 공간이다. 첫 학습 주제는 **AWS Certified AI Practitioner (AIF-C01)**다.

## 학습 순서

1. [[01_AWS AI ML 서비스 비교]] — 서비스 이름과 용도, 시나리오별 선택
2. [[02_AI ML 및 생성형 AI 핵심 개념]] — 학습·추론·FM·RAG·미세 조정 구분
3. [[03_AI Practitioner 서비스 선택 연습문제]] — 자가 점검과 해설

## AIF-C01의 학습 목표

모델을 직접 코딩하는 능력보다 **비즈니스 문제에 맞는 AI 기술과 AWS 서비스를 선택하고, 책임 있게 활용하는 기초 이해**가 중심이다. 개발·배포를 직접 구현하는 작업은 공식 가이드의 대상 직무 범위 밖이지만, 관련 개념과 서비스의 역할은 알아야 한다.

### 공식 시험 영역

2026-10-27 확인한 공식 시험 가이드 기준. 비중은 채점 대상 내용 기준이다.

| 영역 | 비중 | 학습 포인트 |
| --- | --- | --- |
| AI와 ML 기초 | 20% | AI/ML 구분, 학습 방식, 사용 사례 |
| 생성형 AI 기초 | 24% | FM, 토큰, 생성형 AI의 장점과 한계 |
| 파운데이션 모델 활용 | 28% | 서비스·모델 선택, 프롬프트, RAG, 미세 조정 |
| 책임 있는 AI 지침 | 14% | 공정성, 설명 가능성, 신뢰성, 편향 |
| AI 솔루션 보안·규정 준수·거버넌스 | 14% | 접근 제어, 데이터 보호, 감사, 책임 분담 |

> 이 폴더의 첫 문서들은 **서비스 선택의 출발점**이다. 전체 시험 범위를 모두 다룬 완성 교재는 아니며, 나머지 영역은 학습하면서 확장한다.

## 문서와 태그 사용 기준

- AWS 공통: `aws`
- 시험용 교재: `certification`, `study-guide`
- 시험 식별: `aws-ai-practitioner`, `AIF-C01`
- 세부 주제: `ai`, `machine-learning`, `generative-ai`, `bedrock`, `sagemaker` 등
- 연습·오답: `practice`, `review`
- 서비스 명칭·시험 범위를 확인한 날짜를 남기고, 예전 자료의 표현은 현재 명칭과 구분한다.
- 연습문제는 학습용 자체 제작 문제이며 실제 기출·예상 출제를 보장하지 않는다.

## 다음에 확장할 주제

- [ ] 책임 있는 AI: 편향·공정성·설명 가능성·인간 검토
- [ ] 보안·거버넌스: IAM, KMS, CloudTrail, 개인정보 보호, 공동 책임
- [ ] 모델 평가: 정확도·정밀도·재현율, 생성형 AI 평가
- [ ] 비용·성능: 토큰, 지연 시간, 추론 방식, 모델 선택
- [ ] 최신 시험 범위의 추가 서비스: Nova, AgentCore, Kiro 등
