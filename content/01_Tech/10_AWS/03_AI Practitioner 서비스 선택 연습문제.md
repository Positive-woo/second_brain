# AI Practitioner 서비스 선택 연습문제

목차: [[00_AWS 시험 학습 목차]]

**자체 제작 학습 문제**다. 실제 기출문제나 특정 서비스의 출제를 보장하는 자료가 아니다. 답을 가리고 ‘어떤 단서 때문에 선택했는지’를 먼저 설명한다.

## 문제

1. 스캔한 청구서 PDF에서 텍스트·표·양식 필드를 추출하려 한다. Textract와 Comprehend 중 무엇을 고르는가?
2. 추출한 고객 후기의 긍정·부정 감정을 분석하려 한다. 어떤 서비스를 고르는가?
3. 회의 녹음에서 녹취록을 만들고 그 결과를 영어로 번역하려 한다. 서비스 두 개를 순서대로 고르면?
4. 접근 권한이 있는 직원에게만 사내 문서를 바탕으로 생성형 질문 답변을 제공하는 업무 어시스턴트가 필요하다. Q Business와 Q Developer 중 무엇인가?
5. 개발자가 코드 생성·설명·문제 해결 지원을 받고 싶다. 어떤 Q 서비스를 고르는가?
6. 모델 제공 인프라를 직접 관리하는 부담을 줄이며 지원되는 Claude 모델을 API로 호출해 앱을 만들려 한다. Bedrock과 SageMaker AI 중 우선 검토할 서비스는?
7. 자체 ML 모델의 학습·튜닝·배포 환경을 세밀하게 제어하려 한다. 어떤 플랫폼을 고르는가?
8. 사전 학습된 모델을 허브에서 골라 SageMaker AI 환경에 배포하려 한다. 어떤 기능을 찾는가?
9. 사용자 행동 데이터로 상품을 개인화해 추천하려 한다. 어떤 서비스를 고르는가? 데이터 준비 없이 바로 끝나는가?
10. 예약 챗봇이 ‘예약 의도’와 ‘날짜·인원’을 수집해야 한다. 어떤 서비스가 어울리는가?
11. 최신 사내 정책을 근거로 답변하되 모델 가중치는 바꾸지 않으려 한다. RAG와 미세 조정 중 무엇을 먼저 검토하는가?
12. ‘SageMaker는 PyTorch와 같은 ML 프레임워크이고, 미세 조정은 SageMaker에서만 가능하다.’ 이 설명은 맞는가?

## 정답과 해설

| 번호 | 정답 | 판단 이유·오답 구분 |
| --- | --- | --- |
| 1 | Textract | 문서에서 내용과 구조를 추출한다. Comprehend는 텍스트 의미 분석 중심이다. |
| 2 | Comprehend | 텍스트 감정 분석이다. Translate는 번역 서비스다. |
| 3 | Transcribe → Translate | 음성→텍스트 후 언어 번역. Polly는 텍스트→음성으로 반대다. |
| 4 | Q Business | 기업 데이터 기반 업무 어시스턴트. 데이터 접근 권한 설정도 필요하다. |
| 5 | Q Developer | 개발자 작업 지원이다. |
| 6 | Bedrock | 관리형 FM API 활용 요구에 맞는다. 모델·리전의 지원 여부는 확인해야 한다. |
| 7 | SageMaker AI | 모델 수명주기와 학습·배포 구성을 직접 제어하는 요구다. |
| 8 | SageMaker JumpStart | 사전 학습 모델의 탐색·배포를 돕는 기능이다. |
| 9 | Personalize, 준비 필요 | 상호작용 등의 데이터와 해당 구성에 따른 학습·설정이 필요하다. |
| 10 | Lex | 의도(Intent)와 슬롯(Slot) 기반 대화가 단서다. |
| 11 | RAG | 외부 문서를 검색해 문맥으로 제공한다. 미세 조정은 파라미터를 바꾼다. |
| 12 | 틀림 | SageMaker AI는 관리형 플랫폼이다. Bedrock도 지원되는 모델의 미세 조정 기능이 있다. |

## 30초 복습

- 문서 **추출**: Textract / 텍스트 **분석**: Comprehend
- 음성 → 글: Transcribe / 글 → 음성: Polly / 언어 변환: Translate
- 이미지·영상 분석: Rekognition / 의도·슬롯 대화: Lex
- FM API 활용: Bedrock / ML 개발·학습·배포: SageMaker AI
- 사전 학습 모델 허브: JumpStart
- 기업 지식 어시스턴트: Q Business / 개발 지원: Q Developer
- 검색 근거 추가: RAG / 모델 파라미터 변경: 미세 조정
